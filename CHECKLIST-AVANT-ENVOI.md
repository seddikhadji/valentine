## 🆘 PLAN B (Si jamais ça ne marche pas)

Si pour une raison le site ne fonctionne pas :

1. **Vérifie que GitHub Pages est activé**
   - Settings → Pages → Source = main/master

2. **Attends 5 minutes**
   - GitHub a besoin de temps pour déployer

3. **Vérifie l'URL**
   - Format: `https://TON-NOM.github.io/NOM-DU-REPO/`
   - Pas de faute de frappe

4. **Teste en navigation privée**
   - Pour éviter les problèmes de cache

5. **Dernier recours**
   - Supprime le repo et recommence
   - Ça prend 2 minutes
